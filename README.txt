KAVYA SELVARAJ — PERSONAL PORTFOLIO

FILES
- index.html: website content
- style.css: layout, colors, responsive design
- script.js: mobile navigation, copyright year and reveal animations
- images/profile-placeholder.svg: temporary profile image placeholder

RUN LOCALLY
1. Extract this ZIP folder.
2. Open the extracted folder.
3. Double-click index.html to preview in your browser.

ADD YOUR REAL PROFILE PHOTO
1. Copy your portrait photo into the images folder.
2. Name it kavya-profile.jpeg (or use its actual extension).
3. Open index.html and find: images/profile-placeholder.svg
4. Replace it with: images/kavya-profile.jpeg
5. Save the file.

UPLOAD TO GITHUB (REPLACE THE CURRENT SITE)
1. Open https://github.com/kavyaselvaraj29/kavya-portfolio
2. Choose Add file > Upload files.
3. Upload index.html, style.css, script.js and the images folder contents.
4. If GitHub asks to replace existing files, confirm the replacement.
5. Scroll down and click Commit changes (commit directly to main).
6. Open Settings > Pages and confirm Source is Deploy from a branch, branch main, folder /(root).
7. Wait a few minutes, then visit:
   https://kavyaselvaraj29.github.io/kavya-portfolio/
8. Refresh with Ctrl + F5.

IMPORTANT
- Keep index.html, style.css and script.js together in the repository root.
- Keep the images folder at the repository root.
- Do not paste JavaScript into CSS or CSS into JavaScript.
- Check personal details, CGPA, dates, phone number and email before publishing.
